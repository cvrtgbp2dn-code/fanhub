FanHub桌面版

私域拉群进度管理 · 单机版 · 数据只存在你自己电脑上
下载安装包（Windows 64 位）
最新版本 — · 约 107 MB · 支持 Win10 / Win11 · 打不开就点这里
会自动更新：以后工具升级，不用重新下载安装包。 程序每次启动会静默检查一次，有新版本自动换上（更新包只有 131 KB，秒完成）。

这个软件能干什么

  • 导入采集报表（.xls / .csv / .txt），自动按设备分组、按数据ID 去重
  • 勾选 / 自下而上批量选中（个数可自己填）→ 填群名 → 标记已拉群 → 导出表格（已拉群 / 未分配分开导，真 .xlsx）
  • 群组总览：两个设备拼的同一个群，一屏看全，不用来回切设备
  • 云端名单库检测：不在库的人自动打红标，不会误拉
  • 数据备份 / 恢复：换电脑、重装都不丢数据

安装说明

  • 下载后双击安装，可以自己选安装位置
  • 首次打开如果 Windows 弹出「已保护你的电脑」，点 更多信息 → 仍要运行 —— 这是因为个人开发者没买数字签名证书，不是病毒
  • 首次启动需要联网一次（拉最新程序），之后断网也能正常用

数据在哪

  • 全部数据存在你自己电脑上，不上传任何服务器
  • 换电脑：在软件里点「数据备份 → 导出备份文件」，拷到新电脑再「恢复」即可
